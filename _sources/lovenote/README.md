# 爱的排序 · Love Note

11 项原始卡片文字，按照个人重要程度选择、调整顺序，再生成带手写落款的图片。无登录、无后端、无个人答案上报；进度和昵称只保存在浏览器里。

## 构建

使用 Node.js 22.13 或更高版本。

```sh
npm ci
npm run check
npm run build
```

静态输出在 `dist-static/`，发布路径为 `/lovenote/`。将构建内容复制到本仓库的 `lovenote/` 后一起提交，沿用主页部署脚本同步服务器。

## 手机体验

- 单列完整卡片，固定进度、撤回和下一步。
- 44 × 44 像素排序按钮；桌面保留拖动和键盘排序。
- 落款在图片上方；保存图片打开大图，手机长按保存。支持的设备可调用原生分享。
- 分享图为 1080 × 1800 PNG。长昵称最多 16 个字符。
- 纸纹和插画采用压缩后的 ImageGen 素材。较小的中文界面手写字体优先加载；昵称使用完整中文字库。

## 字体

Ma Shan Zheng、Caveat、Noto Serif SC 均来自 Google Fonts，OFL 许可证随字体保留。Noto Serif SC 是当前界面字符的子集；新增中文内容时应补充字形。署名可使用完整 Ma Shan Zheng 字库。

## 验证边界

手机使用浏览器窄屏模拟检查，未声称已经用真机微信或 iOS Safari 验证。保存动作不等于已经分享到任何人。
